# Development guidance

Read and follow [Coding Guidelines](pages/coding-guidelines.md) before making
development changes in this repository. That document is the canonical guide
for Snake Web's development style, documentation, verification, and release ownership.

Read [Project overview](README.md) for the publishing scope and
[DevOps documentation](docs/devops/index.md) before changing installation or
publication workflows. Application code lives here; generated website content
is published to a separate `snake-web` checkout. Snake Lab and Ax3l own their
source schemas and experiment workflows.

Apply these guidelines to new and modified files. Keep changes focused on the
requested task; existing content is not a reason to expand the scope into an
unrelated refactor.
